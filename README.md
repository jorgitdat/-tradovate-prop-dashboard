# 🎯 Tradovate Prop Firm Dashboard

24/7 Live Trading Signals Dashboard - Mobile Accessible

## Features
- ⚡ Real-time trading signals for ES, NQ, GC, MYM, MGC, BTC
- 📱 Mobile-responsive design 
- 🔄 Multi-timeframe analysis (1M, 5M, 15M, 1H)
- 🎯 Live TP/SL targets with R/R ratios
- ⏰ Session-aware trading strategies
- 📊 Live market data via Yahoo Finance
